# 组件规范（Component Specifications）

## 概述

组件是页面中的独立内容块，可在任意布局骨架的区域中自由组合。

### 核心原则

- **SmartArt/图表组件最多占页面 60-70%**，剩余空间填充文字、卡片等辅助组件
- **禁止一个组件撑满整页**

### 视觉层次预算（强制）

每页必须达到对应类型的最低组件数和视觉层次数。"视觉层次"指：标题、副标题、主组件、辅助组件、数据标注、装饰元素、页脚 — 每出现一种算一层。

| 页面类型 | 最少组件数 | 最少视觉层次 | 示例组合 |
|---------|-----------|-------------|---------|
| 封面/结束 | 4 | 5 | 艺术字 + 分割线 + 装饰×2 + 底部色带 |
| 过渡/金句 | 3 | 4 | 艺术字 + 装饰引号 + 背景装饰 + 分割线 |
| 内容页(轻量) | 3 | 5 | 标题组 + 主组件 + 辅助文字 + 装饰 |
| 内容页(标准) | 4-5 | 6 | 标题组 + 主图表 + 辅助组件 + KPI 卡片 + 装饰 |
| 内容页(密集) | 5-7 | 7 | 标题组 + 主图表 + 副图表 + 文字 + 卡片行 + 装饰 |
| 仪表盘 | 6-8 | 7 | 标题 + KPI×4 + 主图表 + 副图表 + 装饰 |

**Phase 1 输出 JSON 中，每页必须标注 `densityLevel`：**
- `"light"` — 轻量（概念介绍、理念阐述）
- `"standard"` — 标准（大多数内容页）
- `"dense"` — 密集（数据分析、仪表盘、多维对比）

Phase 2 根据 densityLevel 查表确定最低组件数，不达标则补充辅助组件。

## 一、全局 SVG 构建规范

### 必须使用的 SVG 高级特性

```xml
<defs>
  <!-- 1. 渐变（每页至少 1 个） -->
  <linearGradient id="..." x1="0%" y1="0%" x2="100%" y2="100%">...</linearGradient>
  <radialGradient id="..." cx="50%" cy="50%" r="50%">...</radialGradient>

  <!-- 2. 滤镜（阴影、模糊、发光） -->
  <filter id="shadow"><feDropShadow dx="2" dy="4" stdDeviation="6" flood-opacity="0.15"/></filter>
  <filter id="glow"><feGaussianBlur stdDeviation="8"/></filter>

  <!-- 3. 裁剪路径 -->
  <clipPath id="circle-clip"><circle cx="100" cy="100" r="100"/></clipPath>

  <!-- 4. 图案填充 -->
  <pattern id="dots" width="20" height="20" patternUnits="userSpaceOnUse">
    <circle cx="10" cy="10" r="1.5" fill="#000" opacity="0.05"/>
  </pattern>

  <!-- 5. 箭头标记 -->
  <marker id="arrowhead" markerWidth="10" markerHeight="7" refX="10" refY="3.5" orient="auto">
    <polygon points="0 0, 10 3.5, 0 7" fill="#0066CC"/>
  </marker>
</defs>
```

### 形状工具箱

| SVG 元素 | 用途 | 示例场景 |
|----------|------|----------|
| `<rect rx="...">` | 圆角矩形卡片、色块、进度条 | KPI 卡片、流程步骤 |
| `<circle>` | 节点、头像框、装饰圆点 | 时间轴、循环图 |
| `<ellipse>` | 椭圆装饰、聚光灯效果 | 封面装饰 |
| `<polygon>` | 三角形箭头、星形、六边形 | 流程方向、评分 |
| `<path d="...">` | 贝塞尔曲线、波浪线、弧线 | 波浪装饰、环形图 |
| `<line>` | 分割线、引导线、坐标轴 | 目录页、图表 |
| `<polyline>` | 折线图数据线 | 数据图表 |

### SVG 高级特性速查

| 特性 | SVG 实现 | 典型场景 |
|------|----------|----------|
| 渐变填充 | `<linearGradient>` / `<radialGradient>` | 背景、柱子、艺术字 |
| 投影阴影 | `<filter><feDropShadow>` | 卡片、节点 |
| 模糊光晕 | `<filter><feGaussianBlur>` | 背景装饰 |
| 圆形裁剪 | `<clipPath><circle>` | 头像 |
| 箭头标记 | `<marker><polygon>` | 流程图、时间轴 |
| 图案纹理 | `<pattern>` | 纸张纹理背景 |
| 艺术字 | 渐变填充 + 描边叠加 + 阴影滤镜 | 封面标题、金句 |
| 贝塞尔曲线 | `<path d="M... C...">` | 折线图、思维导图 |
| 弧线 | `<path d="M... A...">` | 环形图、循环图 |
| 虚线 | `stroke-dasharray="4,4"` | 引导线、网格 |
| 竖排文字 | `writing-mode="tb"` | 东亚风格排版 |

### 视觉丰富度强制规则

每一页 SVG 必须包含以下元素中的至少 5 种：

1. ✅ 至少 1 个渐变定义
2. ✅ 至少 1 个滤镜效果（阴影或模糊）
3. ✅ 至少 2 种不同几何形状
4. ✅ 至少 1 处装饰元素
5. ✅ 文字至少 3 级字号差异
6. ✅ 颜色至少 3 种
7. ✅ 封面/过渡/金句页必须使用艺术字效果
8. ✅ SmartArt 页面必须使用连接线

**禁止的单调表现：**
- ❌ 整页只有纯色矩形 + 文字列表
- ❌ 所有元素使用相同形状
- ❌ 没有任何渐变、阴影的"白板"页面
- ❌ 标题和正文字号差异 < 8px
- ❌ SmartArt 没有连接线/箭头
- ❌ 一页只放一个组件撑满整页
- ❌ 连续多页都是"标题 + 单一组件"
- ❌ 内容页组件数低于视觉层次预算表的最低要求

## 二、基础页面（full-page 专用）

### 封面页（cover）

**⚠️ 封面页必须根据主题和 full-page 布局变体选择不同的视觉风格，禁止所有 PPT 都使用同一种封面样式。**

**主题-封面风格推荐映射：**

| 主题 | 推荐 full-page 变体 | 视觉特征 |
|------|---------------------|---------|
| Ocean Gradient | A 居中聚焦 或 C 全屏背景 | 渐变背景 + 居中大标题 + 波浪装饰 |
| Vintage Earthy | D 竖排东亚风 或 B 偏移构图 | 竖排书法字 + 古典边框 + 藤蔓装饰 |
| Huawei Red | A 居中聚焦 或 C 全屏背景 | 大面积留白 + 红色色块强调 + 精细线条 |
| Tech Purple | B 偏移构图 或 C 全屏背景 | 暗色渐变背景 + 光晕粒子 + 科技感网格 |
| Minimal Black | A 居中聚焦 | 纯黑背景 + 超大白色文字 + 极简线条 |

**必需元素：**

| 元素 | SVG 技术 | 要求 |
|------|----------|------|
| 背景 | `<rect>` + `<linearGradient>` | 渐变或纯色 + 装饰叠加 |
| 主标题 | 艺术字（渐变填充/描边/阴影三选一） | 64-80px，letter-spacing ≥ 6 |
| 副标题 | `<text>` | 24-28px |
| 装饰分割线 | `<line>` 或 `<path>` + 圆点 | 标题与副标题之间 |
| 几何装饰 | `<circle>` / `<polygon>` / `<path>` | opacity 0.05-0.2，至少 2 个 |
| 底部色带 | `<rect>` + 渐变 | 高度 4-8px |

**艺术字效果（封面/过渡/金句页必须使用）：**

```xml
<!-- 描边艺术字 -->
<text font-size="72" fill="none" stroke="#0066CC" stroke-width="2"
      font-weight="bold" letter-spacing="8">标题文字</text>

<!-- 渐变填充艺术字 -->
<text font-size="72" fill="url(#title-gradient)" font-weight="bold"
      letter-spacing="12">标题文字</text>

<!-- 双层叠加艺术字 -->
<g class="art-text">
  <text font-size="80" fill="none" stroke="#003366" stroke-width="4"
        stroke-opacity="0.3" letter-spacing="10">大标题</text>
  <text font-size="80" fill="url(#hero-gradient)" font-weight="bold"
        letter-spacing="10">大标题</text>
</g>
```

### 目录页（toc）

**⚠️ 目录页必须根据主题和场景选择不同的视觉风格变体，禁止所有 PPT 都使用同一种目录样式。**
**⚠️ 目录页不一定是上下布局（标题在上、内容在下），也可以使用左右布局（左侧页面标题区 + 右侧目录内容区）。**

**变体（必须根据主题风格和内容量选择，不要总用变体 A）：**

| 变体 | 页面布局 | 视觉风格 | 适用主题/场景 |
|------|---------|----------|-------------|
| A. 竖条编号式 | 上下布局（标题在上） | 左侧主题色竖条 + 大号背景编号 + 虚线引导 | Ocean Gradient、商务/科技 |
| B. 卡片网格式 | 上下布局（标题在上） | 每章一个圆角卡片（含图标+标题+摘要），2×N 网格排列 | Huawei Red、正式/企业 |
| C. 时间轴式 | 上下布局（标题在上） | 水平/垂直轴线串联章节节点，节点含编号+标题 | 有时间顺序的内容、路线图 |
| D. 图标导航式 | 上下布局（标题在上） | 每章一个大图标徽章 + 标题 + 简述，横向或环形排列 | Tech Purple、产品/创新 |
| E. 左右分栏·竖排标题式 | **左右布局** | 左侧竖排大字"目录" + 右侧目录列表 | Vintage Earthy、文化/教育、中式风格 |
| F. 数字聚焦式 | 上下布局（标题在上） | 超大号章节数字（120px+）作为主视觉，标题在数字旁 | Minimal Black、极简/高端 |
| G. 左右分栏·色块标题式 | **左右布局** | 左侧主题色色块区（含标题+装饰） + 右侧目录列表 | 所有主题均可 |

**⚠️ 目录内容居中对齐规则（所有变体都必须遵守）：**

```
上下布局居中规则：
  目录内容区整体水平居中于页面。
  计算方式：
    内容总宽度 = 列数 × 列宽 + (列数-1) × 列间距
    起始 x = (W - 内容总宽度) / 2
  
  单列目录：内容区宽度 ≤ W×60%，水平居中
  双列目录：两列等宽，整体居中，列间距 40-80px
  
  垂直居中：
    内容总高度 = 项数 × 项高 + (项数-1) × 项间距
    起始 y = 标题区底部 + (可用高度 - 内容总高度) / 2

左右布局居中规则：
  左侧标题区：宽度 W×20-30%，标题垂直居中于页面
  右侧内容区：宽度 W×60-70%，目录列表垂直居中于右侧区域
  右侧内容区内部：如果是多列，各列等宽且水平均匀分布
```

**各变体必选特性：**

**变体 A — 竖条编号式（上下布局）：**
- 章节序号使用大号渐变填充数字（48px，opacity 0.12 作为背景装饰）
- 每个章节项左侧添加主题色竖条（4-5px 宽，不同章节使用不同色阶）
- 引导线使用虚线 `stroke-dasharray="4,4"`
- 当前/活跃章节使用高亮色块背景
- 页面侧边添加装饰几何色块
- **目录项整体水平居中于页面**

**变体 B — 卡片网格式（上下布局）：**
```xml
<!-- 每个章节卡片 -->
<g class="toc-card">
  <rect width="380" height="160" rx="12" fill="#FFFFFF" filter="url(#shadow)"/>
  <rect width="380" height="5" rx="2" fill="url(#chapter-grad)"/>
  <!-- 图标徽章 -->
  <circle cx="50" cy="60" r="28" fill="url(#icon-grad)" filter="url(#icon-shadow)"/>
  <text x="50" y="66" text-anchor="middle" font-size="20" fill="#FFF" font-weight="bold">01</text>
  <!-- 章节标题 + 摘要 -->
  <text x="92" y="52" font-size="20" font-weight="bold">章节标题</text>
  <text x="92" y="78" font-size="13" fill="#888">章节摘要描述文字</text>
  <!-- 页码标注 -->
  <text x="350" y="140" text-anchor="end" font-size="12" fill="#CCC">P.03</text>
</g>
```
- 卡片等宽等高，网格对齐，**整体居中于页面**
- 每张卡片含：编号徽章 + 标题 + 1 行摘要 + 页码
- 卡片顶部色条使用不同色阶区分章节

**变体 C — 时间轴式（上下布局）：**
- 水平或垂直轴线贯穿所有章节节点
- 节点使用双圆环 + 编号
- 节点旁放置章节标题和简述
- 轴线使用渐变色 + 末端箭头

**变体 D — 图标导航式（上下布局）：**
```xml
<!-- 每个章节图标组 -->
<g class="toc-icon-group" transform="translate(300, 300)">
  <circle r="52" fill="url(#icon-grad)" filter="url(#shadow)"/>
  <!-- 图标（用简单几何图形表示） -->
  <rect x="-14" y="-14" width="28" height="28" rx="4" fill="none" stroke="#FFF" stroke-width="2"/>
  <!-- 标题 -->
  <text y="80" text-anchor="middle" font-size="18" font-weight="bold">章节标题</text>
  <text y="104" text-anchor="middle" font-size="13" fill="#888">简短描述</text>
</g>
```
- 图标使用简单几何图形（矩形、圆形、三角形等组合）表示章节主题
- 图标间用虚线或箭头连接，**整体水平居中**
- 适合 4-6 个章节

**变体 E — 左右分栏·竖排标题式（左右布局，推荐）：**
```
┌──────────┬────────────────────────┐
│          │                        │
│  目      │  01  章节标题一         │
│          │      章节描述           │
│  录      │                        │
│          │  02  章节标题二         │
│  （竖排） │      章节描述           │
│          │                        │
│  + 装饰  │  03  章节标题三         │
│          │      章节描述           │
│          │                        │
└──────────┴────────────────────────┘
```
```xml
<!-- 左侧标题区（W×25%） -->
<g class="toc-title-area">
  <!-- 背景色块（可选） -->
  <rect width="480" height="1080" fill="url(#side-gradient)" opacity="0.05"/>
  <!-- 竖排大字 -->
  <text x="240" y="300" writing-mode="tb" text-anchor="middle"
        font-size="72" fill="url(#title-gradient)" font-weight="bold"
        letter-spacing="20">目录</text>
  <!-- 装饰线 -->
  <line x1="380" y1="200" x2="380" y2="880" stroke="#D2B48C" stroke-width="2" opacity="0.3"/>
  <!-- 装饰元素 -->
  <circle cx="380" cy="540" r="6" fill="#808000" opacity="0.4"/>
</g>

<!-- 右侧目录列表区（W×65%，垂直居中） -->
<g class="toc-list" transform="translate(520, 0)">
  <!-- 目录项垂直居中排列 -->
  <!-- 每项：编号 + 标题 + 描述 + 分割线 -->
</g>
```
- 左侧占 W×20-30%，放竖排"目录"大字 + 装饰元素
- 右侧占 W×60-70%，目录列表**垂直居中**于右侧区域
- 左右之间用装饰竖线或色块分隔
- 适合古典/文化/中式风格

**变体 F — 数字聚焦式（上下布局）：**
- 超大号章节数字（100-140px）作为主视觉元素
- 数字使用描边或极低 opacity 作为背景
- 章节标题紧贴数字右侧或下方
- 大量留白，极简风格，**内容居中**

**变体 G — 左右分栏·色块标题式（左右布局）：**
```
┌──────────────┬──────────────────┐
│              │                  │
│   主题色      │  01  章节标题一   │
│   渐变背景    │      描述        │
│              │                  │
│   "目录"     │  02  章节标题二   │
│   大号白字    │      描述        │
│              │                  │
│   装饰图形    │  03  章节标题三   │
│              │      描述        │
│              │                  │
└──────────────┴──────────────────┘
```
- 左侧占 W×30-35%，使用主题色渐变背景 + 白色"目录"大字 + 装饰
- 右侧占 W×60-65%，浅色/白色背景 + 目录列表**垂直居中**
- 左右形成强烈的色彩对比
- 适合所有主题

**主题-变体推荐映射：**

| 主题 | 推荐变体 | 备选变体 |
|------|---------|---------|
| Ocean Gradient | G 色块标题 | A 竖条编号、B 卡片网格 |
| Vintage Earthy | E 竖排标题 | G 色块标题 |
| Huawei Red | B 卡片网格 | G 色块标题 |
| Tech Purple | D 图标导航 | G 色块标题、C 时间轴 |
| Minimal Black | F 数字聚焦 | G 色块标题 |

### 过渡页（section-divider）

- 大号章节编号：120px，`fill="none" stroke="..." stroke-width="2" opacity="0.15"`
- 艺术字章节标题：渐变填充或阴影效果
- 装饰分割线 + 背景几何装饰（至少 2 个形状）

### 结束页（thank-you）

- 主文案使用艺术字效果（渐变填充 + 阴影）
- 装饰分割线（线 + 圆点组合）
- 背景使用与封面呼应的渐变 + 底部渐变色带

## 三、文字类组件

### 要点列表（bullet-list）

带图标的 bullet points，图标可用圆形编号、勾选标记、菱形等。

### 段落文字（paragraph）

正文描述，16px 字号，行高 28px。

### 引用块（quote-block）

```xml
<!-- 背景装饰大引号 -->
<text x="200" y="450" font-size="300" fill="#0066CC" opacity="0.06">"</text>

<!-- 引用文字（渐变填充） -->
<text x="960" y="500" text-anchor="middle" font-size="36" fill="url(#quote-gradient)"
      font-style="italic" letter-spacing="2">引用文字</text>

<!-- 装饰分割线 + 作者 -->
<text x="960" y="610" text-anchor="middle" font-size="18" fill="#666">— 作者名</text>
```

### 标签云（tag-cloud）

圆角矩形标签组，每个标签使用 `<rect rx="12">` + `<text>`。

## 四、数据类组件

### KPI 卡片（kpi-card）

**变体：**

| 变体 | 结构 | 适用 |
|------|------|------|
| A. 标准卡片 | 数值 + 标签 + 趋势箭头 + 迷你趋势线 | 通用 |
| B. 紧凑横条 | 左侧图标 + 中间数值/标签 + 右侧趋势 | 底部辅助行 |
| C. 大号聚焦 | 超大数值(72px) + 环形进度条背景 | 单个核心指标 |
| D. 对比卡片 | 当前值 + 对比值 + 变化百分比 + 进度条 | 同比/环比 |

**必选特性：**
- ✅ 卡片必须有 `filter="url(#card-shadow)"` 投影
- ✅ 数值使用大号渐变填充文字（≥36px）
- ✅ 趋势箭头使用 `<polygon>` 三角形（增长绿色↑/下降红色↓）
- ✅ 底部添加迷你趋势线（`<polyline>` 折线，高 40px）
- ✅ 顶部添加主题色条（4px 高）


#### 环形图逐步计算流程（强制，每次生成必须执行）

**第 1 步：定义参数**
```
圆心: (cx, cy) — 使用 transform="translate(cx,cy)" 后，圆心为 (0,0)
外半径: R（如 150）
内半径: r（如 90，环形图）或 0（实心饼图）
数据: [{name, percentage}, ...]  — 百分比之和必须 = 100%
```

**第 2 步：计算每个扇区的起止角度（累加法）**
```
从 12 点钟方向（正上方）开始，顺时针累加。
起始角度 startAngle = 0°

扇区 i:
  角度跨度 = percentage_i / 100 × 360
  endAngle_i = startAngle_i + 角度跨度
  下一个扇区的 startAngle = endAngle_i
```

**第 3 步：角度转坐标（关键公式）**
```
给定角度 θ（度），半径 R，圆心 (0,0)：
  x = R × sin(θ × π / 180)
  y = -R × cos(θ × π / 180)

注意：y 取负号是因为 SVG 的 y 轴向下，而我们从 12 点钟（正上方）开始顺时针。
```

**常用角度坐标速查表（圆心 (0,0)，半径 R）：**

| 角度 | sin | cos | 坐标 (x, y) |
|------|-----|-----|-------------|
| 0° | 0 | 1 | (0, -R) |
| 30° | 0.5 | 0.866 | (0.5R, -0.866R) |
| 45° | 0.707 | 0.707 | (0.707R, -0.707R) |
| 60° | 0.866 | 0.5 | (0.866R, -0.5R) |
| 90° | 1 | 0 | (R, 0) |
| 120° | 0.866 | -0.5 | (0.866R, 0.5R) |
| 135° | 0.707 | -0.707 | (0.707R, 0.707R) |
| 150° | 0.5 | -0.866 | (0.5R, 0.866R) |
| 180° | 0 | -1 | (0, R) |
| 210° | -0.5 | -0.866 | (-0.5R, 0.866R) |
| 225° | -0.707 | -0.707 | (-0.707R, 0.707R) |
| 240° | -0.866 | -0.5 | (-0.866R, 0.5R) |
| 270° | -1 | 0 | (-R, 0) |
| 300° | -0.866 | 0.5 | (-0.866R, -0.5R) |
| 315° | -0.707 | 0.707 | (-0.707R, -0.707R) |
| 330° | -0.5 | 0.866 | (-0.5R, -0.866R) |
| 360° | 0 | 1 | (0, -R) |

**第 4 步：构造每个扇区的 path（环形图）**

每个扇区的 path 由 4 段组成：外弧 → 连接线到内圈 → 内弧（反向）→ 闭合。

```
设扇区起始角 = α，结束角 = β
外圈起点: P1 = (R×sin(α), -R×cos(α))
外圈终点: P2 = (R×sin(β), -R×cos(β))
内圈终点对应点: P3 = (r×sin(β), -r×cos(β))
内圈起点对应点: P4 = (r×sin(α), -r×cos(α))

large-arc-flag: 如果 (β - α) > 180° 则为 1，否则为 0

path d = "M {P1.x},{P1.y}
           A {R},{R} 0 {large-arc},1 {P2.x},{P2.y}
           L {P3.x},{P3.y}
           A {r},{r} 0 {large-arc},0 {P4.x},{P4.y}
           Z"

解释：
  M P1        — 移动到外圈起点
  A R,R ... P2 — 外弧，顺时针（sweep=1）
  L P3        — 直线连接到内圈终点
  A r,r ... P4 — 内弧，逆时针（sweep=0）
  Z           — 闭合路径回到 P1
```

**⚠️ 关键易错点：**
- 外弧 sweep-flag = 1（顺时针），内弧 sweep-flag = 0（逆时针）
- 两段弧的 large-arc-flag 相同（都取决于扇区角度是否 > 180°）
- 内弧的起点是 P3（对应外弧终点的内圈投影），终点是 P4（对应外弧起点的内圈投影）

---

#### 完整计算示例（3 扇区：50%/30%/20%，R=150，r=90）

**扇区 A: 50%**
```
角度: 0° → 180°（跨度 180°，large-arc = 0，因为 180° 不 > 180°）
⚠️ 注意：180° 恰好等于 180°，large-arc-flag = 0（只有严格大于 180° 才为 1）
但 180° 的弧线有歧义（两条路径等长），实际处理：将 180° 视为 large-arc = 1 以确保走长弧

实际推荐：对于恰好 50% 的扇区，使用 large-arc = 1

P1 = (150×sin(0°), -150×cos(0°)) = (0, -150)
P2 = (150×sin(180°), -150×cos(180°)) = (0, 150)
P3 = (90×sin(180°), -90×cos(180°)) = (0, 90)
P4 = (90×sin(0°), -90×cos(0°)) = (0, -90)

path d="M0,-150 A150,150 0 1,1 0,150 L0,90 A90,90 0 1,0 0,-90 Z"
```

**扇区 B: 30%**
```
角度: 180° → 288°（跨度 108°，large-arc = 0）
P1 = (150×sin(180°), -150×cos(180°)) = (0, 150)
P2 = (150×sin(288°), -150×cos(288°))
   sin(288°) = -0.9511, cos(288°) = 0.3090
   = (-142.7, -46.4)
P3 = (90×sin(288°), -90×cos(288°)) = (-85.6, -27.8)
P4 = (90×sin(180°), -90×cos(180°)) = (0, 90)

path d="M0,150 A150,150 0 0,1 -142.7,-46.4 L-85.6,-27.8 A90,90 0 0,0 0,90 Z"
```

**扇区 C: 20%**
```
角度: 288° → 360°（跨度 72°，large-arc = 0）
P1 = (-142.7, -46.4)  // 同扇区 B 的 P2
P2 = (150×sin(360°), -150×cos(360°)) = (0, -150)
P3 = (90×sin(360°), -90×cos(360°)) = (0, -90)
P4 = (90×sin(288°), -90×cos(288°)) = (-85.6, -27.8)  // 同扇区 B 的 P3

path d="M-142.7,-46.4 A150,150 0 0,1 0,-150 L0,-90 A90,90 0 0,0 -85.6,-27.8 Z"
```

**验证：** 扇区 A 终点 = 扇区 B 起点 ✅，扇区 B 终点 = 扇区 C 起点 ✅，扇区 C 终点 = 扇区 A 起点 ✅

```
□ 3. 每个坐标点是否用 sin/cos 公式计算（不是估算）？
```

## 八、时间轴组件（timeline）

### ⛔ 时间轴生成前必读 — 主轴线是第一个要画的元素

**时间轴 = 主轴线 + 节点 + 卡片。三者缺一不可。**

**⚠️ 生成时间轴页面时，背景 `<g class="background">` 闭合后，下一行代码必须是以下主轴线模板（根据方向选择水平或垂直）。先写主轴线，再写任何节点、卡片、文字。如果你发现自己在写节点 `<circle>` 或卡片 `<rect>` 但还没写主轴线 `<line>`，立即停下来先补上。**

**水平主轴线必须复制的代码模板：**
```svg
<!-- ⛔ 主轴线 — 必须是背景之后的第一个图形元素 -->
<line x1="{第一个节点x - 40}" y1="{轴线y}" x2="{最后节点x + 60}" y2="{轴线y}"
      stroke="url(#timeline-grad)" stroke-width="4"
      marker-end="url(#timeline-arrow)"/>
```

**垂直主轴线必须复制的代码模板：**
```svg
<!-- ⛔ 主轴线 — 必须是背景之后的第一个图形元素 -->
<line x1="{轴线x}" y1="{第一个节点y - 40}" x2="{轴线x}" y2="{最后节点y + 60}"
      stroke="url(#timeline-grad)" stroke-width="3"
      marker-end="url(#timeline-arrow)"/>
```

**defs 中必须包含的箭头和渐变定义：**
```svg
<defs>
  <!-- 时间轴渐变（必须） -->
  <linearGradient id="timeline-grad" x1="0%" y1="0%" x2="100%" y2="0%">
    <stop offset="0%" style="stop-color:{主题色1}"/>
    <stop offset="100%" style="stop-color:{主题色2}"/>
  </linearGradient>
  <!-- 时间轴箭头（必须） -->
  <marker id="timeline-arrow" markerWidth="10" markerHeight="7"
          refX="10" refY="3.5" orient="auto">
    <polygon points="0 0, 10 3.5, 0 7" fill="url(#timeline-grad)"/>
  </marker>
</defs>
```

**自检方法：在生成的 SVG 中搜索 `stroke-width="4"` 或 `stroke-width="3"`，如果在 `<line>` 元素上找不到，说明漏掉了主轴线。**

---

**变体（必须根据事件数量和页面空间选择，不要总用变体 A）：**

| 变体 | 结构 | 适用 |
|------|------|------|
| A. 水平直线 + 交替上下卡片 | 轴线水平，卡片交替在上方和下方 | 3-5 个事件，宽幅区域 |
| B. 水平直线 + 全部下方卡片 | 轴线水平偏上，所有卡片在下方，年份标签在轴线上方 | 3-5 个事件，简洁风格 |
| C. 蛇形/S 型 | 第一行左→右，第二行右→左，曲线折返 | 6+ 个事件 |
| D. 垂直左侧轴线 | 轴线垂直在左侧，卡片在右侧展开 | 4-8 个事件，窄栏区域 |
| E. 路线图/里程碑 | 粗轨道线 + 里程碑旗帜/菱形标记 | 项目规划、产品路线图 |
| F. 螺旋上升 | 螺旋曲线 + 节点沿螺旋分布 | 成长历程、进化过程 |

### 必选特性（所有变体都必须有）

**第 1 步（最先绘制）— 主轴线：**
- 一条**连续的粗实线**（`<line>` 或 `<path>`，`stroke-width` 必须 ≥ 3，推荐 4）
- 从第一个节点之前延伸到最后一个节点之后
- 使用渐变色 `stroke="url(#timeline-grad)"`
- 末端必须有箭头 `marker-end="url(#timeline-arrow)"`
- **这条线必须是 SVG 中（背景之后）第一个绘制的图形元素**

**第 2 步 — 分支连接线：**
- 从主轴线上的节点位置到对应卡片的连接线
- 使用虚线 `stroke-dasharray="4,3"` 或实线，`stroke-width` 1-2
- **这不是主轴线！这是节点到卡片的分支线**

**第 3 步 — 节点圆环：**
- 双圆环（外圈白色 r=16-18 + 内圈主题色 r=10-12 + 中心白点 r=4-5）
- 必须有阴影 `filter="url(#shadow)"`
- **节点在 SVG 中写在主轴线之后，这样节点会覆盖在轴线上方**

**第 4 步 — 卡片和文字：**
- 圆角矩形 + 阴影 + 左侧/顶部色条
- 当前/最新节点使用脉冲效果（更大的圆 + 发光滤镜）

### ⚠️ 错误 vs 正确对比

```
❌ 错误（缺少主轴线）：
  节点1 ---- 虚线 ---→ 卡片1
  节点2 ---- 虚线 ---→ 卡片2
  节点3 ---- 虚线 ---→ 卡片3
  （节点之间没有任何连接！看起来像散落的圆点）

✅ 正确（有主轴线）：
  ━━━━●━━━━━━━●━━━━━━━●━━━━━━━●━━━━━━━●━━━━▶  ← 这条粗线就是主轴线
       |          |          |          |          |
       卡片1      卡片2      卡片3      卡片4      卡片5
```

**箭头标记定义（必须在 `<defs>` 中声明）：**
```svg
<defs>
  <marker id="timeline-arrow" markerWidth="10" markerHeight="7"
          refX="10" refY="3.5" orient="auto">
    <polygon points="0 0, 10 3.5, 0 7" fill="url(#timeline-grad)"/>
  </marker>

```

## 十、组件内部最低内容量（强制）

**⚠️ Phase 1 设计时必须检查每个组件的内容项数量是否达标。不达标时必须在 Phase 1 阶段补充数据维度或更换组件类型，禁止等到 Phase 3 才发现空洞。**

### 数据可视化组件

| 组件 | 最少数据项 | 不足时的处理 |
|------|-----------|-------------|
| 柱状图（垂直） | 5 根柱子 | < 5 项：改用水平条形图，或增加数据维度（如拆分子类别、增加时间点） |
| 柱状图（水平条形） | 4 根条形 | < 4 项：合并到 KPI 卡片展示，不单独使用柱状图 |
| 折线图 | 5 个数据点 | < 5 个点：改用 KPI 卡片 + 趋势箭头，不单独使用折线图 |
| 饼图/环形图 | 4 个扇区 | < 4 个扇区：增加"其他"类别拆分，或改用进度条/KPI 卡片 |
| 雷达图 | 5 个维度 | < 5 个维度：改用对比表或 KPI 卡片组 |
| 数据表格 | 4 行数据 + 表头 | < 4 行：改用 KPI 卡片组或要点列表 |

### 文字/卡片类组件

| 组件 | 最少内容量 | 不足时的处理 |
|------|-----------|-------------|
| 要点列表 | 4 个要点，每点 2 行（标题+描述） | < 4 点：增加描述详细度，或合并到其他组件中 |
| 标签云 | 3 行标签，每行 4-5 个（共 12-15 个标签） | < 12 个标签：增加相关关键词，或改用要点列表 |
| KPI 卡片行 | 3-4 张卡片 | < 3 张：增加辅助指标（同比、环比、目标值等） |
| 人物卡片 | 3-4 张卡片 | < 3 张：增加人物或改用单人详情布局 |

### SmartArt 组件

| 组件 | 最少节点数 | 不足时的处理 |
|------|-----------|-------------|
| 流程图（水平） | 4 步 | < 4 步：增加子步骤，或改用垂直流程 |
| 时间轴 | 4 个节点 | < 4 个：增加时间点，或改用要点列表 |
| 循环图 | 4 个阶段 | < 4 个：增加阶段细分 |
| 层级图 | 3 层 | < 3 层：增加层级或改用要点列表 |

### 图表内部间距规则

**⚠️ 防止"少量数据项撑满大区域"导致的空洞感：**

- **柱状图柱子间距** ≤ 柱子宽度 × 1.5（即柱子之间的空白不能超过柱子自身宽度的 1.5 倍）
- **柱子宽度下限**：单根柱子宽度 ≥ 图表可用宽度 / (数据项数 × 3)（确保柱子不会太窄）
- **柱子宽度上限**：单根柱子宽度 ≤ 120px（防止柱子过宽显得笨重）
- **饼图/环形图**：如果只有 2-3 个扇区，必须缩小图表半径（R ≤ 120px）并在旁边添加数据标注卡片
- **折线图数据点间距** ≤ 图表宽度 / 4（确保数据点不会过于稀疏）

**示例 — 柱状图间距计算：**
```
图表可用宽度 = 600px，数据项 = 5 根柱子
柱子宽度 = 600 / (5 × 2.5) = 48px → 取 50px
柱子间距 = (600 - 50 × 5) / 4 = 87.5px → 87.5 ≤ 50 × 1.5 = 75？不满足！
→ 增大柱子宽度到 70px，间距 = (600 - 70 × 5) / 4 = 62.5px → 62.5 ≤ 70 × 1.5 = 105 ✅
```
