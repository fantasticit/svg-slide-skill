# SVG Slide Skill

专业幻灯片自动生成技能 — 通过纯 AI 技能编排，将用户的主题或大纲自动转化为高质量 SVG 幻灯片。

## 它能做什么？

给出一个主题（比如"2024 年 Q3 销售汇报"）或内容大纲，技能会自动完成：

1. 需求解析与内容扩写
2. 逐页生成精美的 SVG 幻灯片
3. 质量审查与自动修复
4. 打包交付（SVG 文件 + HTML 预览页 + ZIP）

生成的每一页都是独立的 SVG 文件（1920×1080，16:9），包含渐变、阴影、图表、SmartArt 等丰富的视觉元素。

## 工作流程

```
Phase 0  需求澄清 — 确认页数、受众、主题色等关键信息
    ↓
Phase 1  内容设计 — 解析需求，规划每页的布局与组件组合，输出结构化 JSON
    ↓
Phase 2  SVG 生成 — 加载主题配置，坐标预计算，逐页生成 SVG 代码
    ↓
Phase 3  质量审查 — 溢出/重叠/空白/对比度/图表精度等 8 大类逐项检查
    ↓
Phase 4  交付保存 — 文件组织、HTML 预览页生成、ZIP 打包
```

## 设计体系

### 布局骨架（5 种）

| 布局 | 用途 | 变体数 |
|------|------|--------|
| `full-page` | 封面、过渡页、结束页、金句页 | 4 |
| `title-body` | 通用内容页 | 5 |
| `title-split` | 对比、图文混排 | 6 |
| `title-body-footer` | 主内容 + 底部摘要 | 4 |
| `dashboard` | 数据密集型仪表盘 | 4 |

### 组件库（30+）

涵盖文字类（要点列表、段落、引用块、标签云）、数据类（KPI 卡片、柱状图、折线图、饼图、环形图、雷达图、数据表格）、SmartArt 图解（流程图、循环图、层级图、树形图、矩阵图、维恩图、时间轴）、媒体类（人物卡片、图标徽章）及装饰类组件。

高频组件均提供 3-6 种变体，并定义了必选视觉特性（渐变、阴影、连接线等）。

### 主题（5 种）

| 主题 | 适用场景 |
|------|----------|
| Ocean Gradient（海洋渐变） | 商务汇报、科技发布、数据分析 |
| Vintage Earthy（复古大地色） | 古典文学、历史文化、传统行业 |
| Huawei Red（华为红） | 企业发布、品牌宣传、正式场合 |
| Tech Purple（科技紫） | AI 产品、创新技术、未来感 |
| Minimal Black（极简黑） | 高端发布会、艺术设计、极简风格 |

## 使用方式

在 Kiro 中直接对话即可触发，例如：

- "帮我做一个 2024 年 Q3 销售汇报的 PPT，8 页"
- "新产品发布会开场 PPT，产品名'智擎 AI'，科技感强一些，10 页"
- "红楼梦人物关系分析的课件，用于高中语文教学，8 页"

技能会先确认页数、受众、主题色等关键信息，然后自动完成全部生成流程。

## 质量保障

每页 SVG 生成后会经过严格的审查清单：

- 溢出检查 — 元素不超出画布安全区
- 重叠检查 — 文字行距、组件间距达标
- 空白检查 — 内容区填充率 ≥ 80%，垂直居中验证
- 对称性检查 — 多列等宽等高，分栏高度平衡
- 对比度检查 — 暗色主题文字可读性
- 图表精度检查 — Y 轴对齐、柱高比例、饼图角度
- 时间轴轴线检查 — 主轴线完整性
- 箭头方向检查 — 流程图方向一致性
